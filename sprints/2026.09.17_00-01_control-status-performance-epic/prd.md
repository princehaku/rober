# 控制与状态性能需求

## 状态与价值

- 状态：PRD completed；前置 `pre_start.md` 已完成。
- O7 用户价值：停止操作可以及时进入发送链；状态刷新不会中断视频或重复请求。
- 手机用户价值：首屏集中显示任务与安全状态，任务进展可以持续更新；诊断内容按需展开。
- O10 支撑价值：控制可响应与状态可信是后续受控送达的前置质量；本轮软件性能证据不提升 O10 完成度。
- 方向：继续产品北极星；按 CEO 本轮明确要求优先修性能。本轮不调整硬件或导航路线。

## 产品约束

- 保持现有端点、动作 payload 与错误结构兼容；新增缓存采样时间可作为可选字段。
- 不为降低 CPU 牺牲 Stop、自动停车、过期状态提示或 fail-closed 安全 gate。
- 手机诊断与验收功能保留访问入口；首屏默认只承担任务和核心安全状态。
- 性能证据给出 baseline/after 或可审计的结构性计数；阈值、样本数、mock 注入延迟必须记录。
- 实机 CPU、手机真机首屏、4G 链路、硬件停止时延均待后续现场测量。

## 完成条件

工程测试、构建、必要修复完成；相关 docs 同步；集成 owner 输出 artifact；随后依次写 tech-done、side2side_check、final。完成 KR 只以软件证据进入历史记录，现场验证项保留为未验证。
