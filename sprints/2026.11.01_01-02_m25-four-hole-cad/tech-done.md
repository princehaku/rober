# 四孔金属安装接口迭代

sprint_type: micro

状态：CAD 范围完成，独立资料/规格/质量复核通过，进入正常 Git 交付。用户先说“我现在是从这四个孔用M6螺丝安装的 继续修改设计”，后补“对应小车一层的孔是这里”，并明确纠正“你说的对 是2.5mm的”。本轮采用M2.5，建立上下层四孔与金属结构的同轴关系，保留中央单丝杆后卸，交付可修改参考 CAD 和孔距样板。不改 OKR 完成度。

## 最小计划

- owner：robot-hardware-engineer，单线实现、导出、验证和修复。主节点及独立 reviewer 只读核对资料/验收。
- 范围：现有 `docs/hardware/cad/ground_dump_v0/`，本 sprint 文件；额外依赖仅写已忽略 `tools/cad-python/`。不改 vendor、产品代码、旧 sprint。
- 先核对两张用户截图对应的 DXF 四耳/车顶孔，明确单位、OCS/WCS、原孔径、孔组偏置及90°映射；截图只用来识别轮廓，不按像素推尺寸。
- 参数化四孔轴线、金属隔柱/耳位、上下承力梁、螺栓通道与工具空间；新增轻薄连通的对位样板仅用于孔距试装。厂家原孔和新增件间隙分开描述。
- 验收：运行可重复资料提取及 CAD 导出；检查三类既有打印件和新样板的封闭/单连通/正体积/Z=0；测网格真实孔距、通径、脚/孔联动；验证保存单件+柱距95的回归；查看运输、卸料与四孔安装图；检查空白和中文注释比例。
- 资料边界：上层四孔58×86、原孔径2.6，下层86×58、原图孔径2.05。最初与“M6”冲突时已立即升级，用户确认改为M2.5。下层未见攻牙标注，原圆径与用户安装规格分开保留，暂不声明下层为M2.5贯穿孔。

## 实际改动

- `ground_dump.scad`：安装原点为四孔组中心，前架/翻斗保留车体局部布局；下层参考板相对孔组偏置22.641541 mm。四根中空金属隔柱、带孔横梁和外移主纵梁按孔轴对齐；新件通孔默认3.0 mm、螺纹2.5、头/垫片/工具空间独立参数化。原上层2.6及下层图示2.05孔不被改写。整体180°参数仅调整展示，真实车头映射仍待实物确认。
- 前传感器 `base_adapter` 从140缩短为50×120×6，四处底盘紧固点留在板后方。用户加长时，工具窗按孔轴联动；距边不足3 mm时开口到边缘，避免薄筋。新增前金属横梁保持传感器底座/立柱与主梁连接。
- 新增 `mount_template.stl`：70×98×2.5，四孔58×86、设计通孔3.0；仅作对位样板，禁止承重。现有雷达板/相机座保留；底座适配件更新。
- `extract_mount_reference.py`、`mount_reference.json`、`mount_dxf_reference.png`：实际解析两份DXF，保留句柄、原始OCS/WCS、法向、毫米单位、块缩放和偏置；按相同安装方向重画两张顶视曲线。用户原截图未复制到Git。
- `export.ps1`、`validate.py`：导出原打印件、样板、金属框架和前适配件检查网格；直接对实际三角网格切片，拟合四孔中心和通径，检查孔距改参同步及螺头/工具圆盘开放。固定回归显式使用M2.5/3mm间隙/10mm工具径，生产单件保持用户当前源参数。
- `exports/` 更新运输、卸料、机构和双状态概览，新增安装侧视/俯视原图及带H1-H4、O原点、58/86标注的 `mount_installation.png`，同步几何JSON和回归STL。`*_check.stl`不供打印，金属框架检查件可含多个装配实体。
- `README.md` 同步用户规格纠正、四孔坐标/90°映射、局部与安装坐标关系、参数、工具路径、打印和装配顺序、风险。

### 定位与修复

- 起初按圆心原始负X筛选导致参考轮廓为空，定位为DXF负Z法向的OCS/WCS差异，改为统一WCS读取；不使用截图像素。
- 最初螺纹声明与原孔径矛盾，立即升级，用户纠正M2.5后统一默认/命名；保留下层图示圆径和未确认的连接类型。
- 独立review发现原140前适配板覆盖四螺头，缩短默认板并增加参数联动工具窗/薄筋开边，通过默认及140板+改距的实际网格验收。
- 单独检查曾与正在重导出的同名文件删除时刻冲突；待导出完成后串行检查通过，正式入口本身按导出→检查顺序执行。

所有技术注释使用中文；最终行数比例另以本轮完成检查输出核对，均超过20%。`git diff --check`及新增文本空白检查通过；未更改vendor、OKR、其他代码、旧sprint或工具二进制跟踪策略。

## 剩余风险

M2.5来自用户确认，厂家下层图示2.05孔未提供攻牙说明；螺柱连接类型、啮合长度、紧固力矩、实测孔距/现有改孔情况仍待实物核对。板厚、层高、隔柱、安装耳、螺头/垫片/工具包络均为设计占位，整机总载荷/2kg垃圾、悬臂梁刚度、丝杆推力、全行程、防夹和防倾覆未经计算或HIL。原板外形在整机中简化，孔位证据来自DXF且保留偏置；真实前后映射待确认。本轮交付为可改CAD、孔距样板和几何/局部空间证据，不批准负载上车。
