# PLA 首次试打：先对四孔，再打传感器件

先用 `exports/mount_template.stl` 试装。当前打印机与喷嘴型号尚待确认；下表仅为 **0.4 mm 喷嘴**的建议起点。PLA 本轮用于对位和传感器试装；主架、隔柱及翻斗/执行器的承力连接沿用金属方案，斗体材料与工艺仍待确定，2 kg 负载未验证。

## 第一件照着做

1. 在适配你的打印机的切片器里选择**准确机型、喷嘴及耗材厂商 PLA 预设**；温度、冷却、速度沿用对应预设。
2. 导入 `exports/mount_template.stl`，单位 **mm**、缩放 **100%**，尺寸应为 **70 × 98 × 2.5 mm**。保持原方向，平面落床，关闭自动缩放适应平台。
3. 按下表设置，检查逐层预览：首层四耳和连接条连续、四孔贯通，无悬空孤岛；支撑关闭。成型范围需容得下模型及可能的裙边。
4. 由你在确认机型配置后生成该机适用文件并手动开始打印；先观察首层。完全冷却后取件、去毛刺，用实际M2.5螺丝空载核对四孔能否同时对齐，孔距应为 **58 × 86 mm**。不要强拧螺丝穿PLA，也不要扩动原金属孔。
5. 孔小、四孔错位或板翘时先停在样板阶段：分别检查首层挤压/象脚、孔径补偿和实际孔距；需要时修改源参数后重导出。对位成功再量雷达/相机实物孔距和外形，确认后分别打印其余三件。

## 0.4 mm 喷嘴建议起点

| 设置 | 本次试打建议 |
|---|---|
| 材料、温度、速度、冷却 | 对应机型与耗材厂商的PLA预设；不套用其他机器温度 |
| 层高 / 首层 | 0.20 / 0.20 mm |
| 壁数 | 3道；相机座可从4道起 |
| 顶层 / 底层 | 各4层，最终看切片预览连续封面 |
| 填充 | 20%，保留预设填充图案 |
| 支撑 / 附着 | 按下表逐件检查；首层稳定先不加brim，若翘边再试外侧3–5 mm brim |

这些数值是本项目试打选择，尚未切片或实打确认；增加填充和壁数不等于通过承载验证。

## 四件的朝向与支撑

| 文件（均在 `exports/`） | 默认尺寸 mm | 原始落床面与支撑判断 |
|---|---|---|
| `mount_template.stl` | 70×98×2.5 | 2.5厚的框形平底向下，四孔轴竖直；无需支撑 |
| `lidar_plate.stl` | 70×110×5 | 70×110的大平面向下，孔槽竖直贯通；无需支撑 |
| `base_adapter.stl` | 50×120×6 | 50×120的大平面向下；默认孔竖直贯通，无需支撑 |
| `camera_bracket.stl` | 48.870×64×43.392 | **42×64的水平底板向下，带两侧筋的斜板立起**，不要把斜板误放成底面；支撑见下段 |

相机斜板只偏离竖直10°，可先按原方向检查；它的两个约3.4 mm安装孔近水平方向贯穿，孔上沿会出现短桥接/悬垂。重点逐层看孔顶、外倾面的新生轮廓：若出现无承托线段、切片警告，或该机桥接能力尚未验证，在相应孔顶/外倾区加**可拆的局部支撑**，确认预览确实生成且取出通道可达；不要把整件孔槽塞满支撑。常规外倾壁有前层承托时可先不加该处支撑，最终依实际切片和试打决定。[Prusa：打印朝向与悬垂](https://help.prusa3d.com/article/modeling-with-3d-printing-in-mind_164135)

只打印上述四件；`*_check.stl`、整机装配和金属框架检查网格不供打印。PLA对温度、紫外线和长期受力的适用性有限，本轮仅验证试装流程，长期上车材料和紧固仍待验证。[Prusa：PLA](https://help.prusa3d.com/article/pla_2062?product=mini)、[层高与壁数](https://help.prusa3d.com/article/layers-and-perimeters_1748)
